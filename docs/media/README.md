# Media inventory

Current Montage release media must be captured from the validated release
commit and named with the `montage-` prefix described in
[`docs/release/marketplace.md`](../release/marketplace.md).

The current repository diagram is `montage-repositories.svg`. The previous
active screenshots were Ress-branded. They are retained under
`archive/` as historical material and are intentionally not referenced by the
README, current site, marketplace submission, or current workflows.

Required clean-machine captures before marketplace submission:

- `montage-panel-1.0.0.png` — all four tabs and Montage title;
- `montage-repositories-1.0.0.png` — repository, loadout, and backup selection;
- `montage-share-1.0.0.png` — selected-loadout composition; and
- `montage-open-graph-1.0.0.jpg` — 1200×630 release artwork.

Each capture belongs in the dated evidence log described by
[`fresh-machine-validation.md`](../testing/fresh-machine-validation.md).
