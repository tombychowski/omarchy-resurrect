Montage composes constrained, portable Omarchy loadouts; publishes them in inspectable libraries; and applies and reconciles them without claiming unrelated machine state.

# inspect a library and preview one loadout
$ mntg repository loadouts personal --json
$ mntg apply --dry-run personal --loadout workstation

# apply, then reconcile from exact recorded provenance
$ mntg apply personal --loadout workstation
$ mntg loadout check --json

Install

$ omarchy plugin add https://github.com/tombychowski/omarchy-montage --enable
$ ~/.config/omarchy/plugins/tombychowski.montage/bin/mntg link
$ mntg doctor

No account and no hosted control plane. The plugin id is tombychowski.montage; the command is mntg.

One artifact, three surfaces

Libraries

Browse stable loadouts in validated local Git repositories and synchronize with conservative, explicit history actions.

Compose / Share

Select packages, pinned plugins, reconstructible web apps, and one theme. Arbitrary files and commands do not travel.

Applied Loadouts

See drift, repair work, and explicitly previewed updates from exact local evidence.

$ mntg repository sync personal --json
$ mntg share --repository personal --loadout minimal --custom --select package:fd
$ mntg status --json

Trust boundaries

Preview and consent

Application is additive, and AUR work remains a separate choice.

Preserve unrelated state

Cleanup follows validated native claims; it never infers broad ownership.

Conservative Git

Fast-forward pull and ordinary push only. Divergence is decision-required.

CLI authority

The panel consumes versioned mntg output and never interprets Git or state files.

Moving one Ress loadout

Montage has one focused compatibility boundary. It reads one Ress v1 profile and publishes a separately selected Montage library item.

$ mntg port ress inspect /path/to/ress-profile --json
$ mntg --dry-run port ress import loadout /path/to/ress-profile \
    --repository personal --loadout imported-ress \
    --ress-plugin omit --montage-plugin omit --json

The source remains untouched. Montage adopts no Ress configuration, operational state, credentials, machine identity, or Git history, and provides no reverse conversion.
